## 💻 Technical Overview of the Source Code

**DDX** is a robust desktop application developed in **Python**, designed to solve, analyze, and visualize complex differential and integral calculus problems. The software architecture was built with a focus on symbolic precision, advanced numerical methods, and a modern, responsive graphical user interface.

### Tech Stack and Libraries Used

The application integrates multiple high-level libraries to ensure performance and accuracy in calculations:

* ** graphical User Interface (GUI):** `customtkinter` and `tkinter` for rendering a Dark Mode interface featuring a tab system and real-time mathematical expression validation.
* **Symbolic Computer Algebra System (CAS):** `sympy` serves as the core mathematical engine, responsible for solving derivatives, integrals, limits, algebraic simplifications, and strict domain and range calculations.
* **Numerical Computing:** `numpy` and `scipy` (specifically `scipy.optimize.fsolve` and `scipy.interpolate.interp1d`) for finding numerical roots, performing cubic spline interpolation of discrete data, and adjusting sample resolution in complex functions.
* **Data Visualization:** `matplotlib` integrated directly into Tkinter (`FigureCanvasTkAgg`), enabling interactive plotting of Cartesian graphs, asymptotes, critical points, and inflection points.

### Architecture of Main Features

The code is structured around a main application class (`App`) that manages the rendering of isolated instances for each mathematical domain. The main implemented features include:

1. **Domain and Range Analysis:**
   * A complex algorithm that detects singularities, denominator constraints, fractional powers, and logarithmic arguments using SymPy, returning a formal set-theory analysis (`Interval`, `Union`, `FiniteSet`).

2. **Limits Engine and L'Hôpital's Rule:**
   * One-sided and two-sided limit calculations.
   * Iterative implementation of L'Hôpital's Rule for indeterminate forms ($0/0$ or $\infty/\infty$), demonstrating step-by-step differentiation of the numerator and denominator.

3. **Advanced Differentiation:**
   * **Single and Higher-Order Derivatives:** Symbolic calculation with tangent line evaluation at specific points.
   * **Partial Derivatives:** Support for multivariable functions by isolating variables for differentiation.
   * **Implicit Differentiation:** Utilizes `sp.idiff` to find $dy/dx$ in non-isolated equations.

4. **Numerical and Symbolic Integration:**
   * Resolution of definite integrals (with integration limits) and indefinite integrals (returning the constant of integration).

5. **Smart Plotting and Graphics:**
   * Support for standard functions and piecewise-defined functions.
   * Automatic detection and plotting of:
     * Asymptotes (Vertical, Horizontal, and Oblique).
     * Critical Points (Maxima, Minima, and Saddle Points).
     * Inflection Points and visual shading of concavity regions (positive/negative).
     * Intervals of increase and decrease.
   * Import and cubic spline interpolation of data points from `.txt` files.
